### Build and Installation

</div>

Container-based setup is recommended. Use the linked guides for prerequisites, configuration, and platform-specific steps.

| Component | Container setup (recommended) | Manual setup |
| :--- | :--- | :--- |
| Flutter | [Container guide](docs/setup/flutter-container-setup.md) | [Manual guide](docs/setup/flutter-manual-setup.md) |
| Backend | [Container guide](docs/setup/backend-container-setup.md) | [Manual guide](docs/setup/backend-manual-setup.md) |

#### Flutter quick start

```sh
make -C docker flutter-build-image
make -C docker flutter-test
```

#### Backend quick start

```sh
make -C docker backend-up
curl http://localhost:8000/health
```
